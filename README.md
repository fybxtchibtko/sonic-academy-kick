## Overview

KICK 2 is the most-used kick synthesizer in electronic dance music, building kick drums entirely from synthesis with click layer, body synthesis, pitch envelope, and a multiband distortion chain.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sonic Academy KICK** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Click Layer** | Transient click synth with noise, tone, and sample blending options |
| **Body Synthesis** | Sine-based body with pitch envelope decay and harmonic drive |
| **Pitch Envelope** | Dedicated exponential pitch drop with start frequency and time |
| **Multiband Distortion** | Four-band saturation chain for modern punchy kick character |
